# Security Policy

## Supported Versions

Security fixes are provided for the latest release.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use [GitHub's private vulnerability reporting](https://github.com/alikarpykov/fs-linker/security/advisories/new) to report a vulnerability privately. Include steps to reproduce the issue and its potential impact.

Please allow the maintainer time to investigate before publicly disclosing the issue.
